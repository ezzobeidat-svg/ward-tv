# לוח המחלקה – מסך טלוויזיה למחלקה (GitHub בלבד)

מסך שמציג למטופלים את המידע הבא:
- שעה, תאריך לועזי ותאריך עברי
- סדר היום, ארוחות ותרופות
- הרופאים והצוות שנמצאים היום, מנהל/ת המחלקה והמזכירה
- שעות ביקור וטלפון המחלקה
- הודעות, קבוצות ריפוי בעיסוק ותמונות
- משפטים מרגיעים מתחלפים
- כניסת ויציאת שבת
- מסך "לילה טוב" בשעות השינה

**הכול יושב ב-GitHub, בלי שום שירות חיצוני.** הקוד מתפרסם ב-GitHub Pages, וכל המידע נשמר בקובץ `data.json` בתוך ה-repo. כל עדכון של איש צוות נשמר כ-commit, כך שיש היסטוריה מלאה של מי שינה מה ומתי.

## הקבצים
| קובץ | מה הוא עושה |
|---|---|
| `index.html` | המסך שרץ בטלוויזיה |
| `admin.html` | דף העדכון לצוות (מהטלפון) |
| `setup.html` | הגדרה חד-פעמית: מצפין את הטוקן |
| `config.js` | הגדרות |
| `data.json` | כל המידע (מתעדכן מדף הצוות) |

## התקנה (פעם אחת)

### 1. יצירת ה-repo
1. ב-GitHub: **New repository** (למשל `ward-tv`). העלה את כל הקבצים.
2. **Settings → Pages → Source: Deploy from a branch → main → / (root) → Save**.
3. אחרי דקה-שתיים האתר זמין בכתובת `https://USER.github.io/ward-tv/`.

### 2. יצירת טוקן עם הרשאה רק ל-repo הזה
1. ב-GitHub: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. **Repository access → Only select repositories** ← בחר רק את `ward-tv`.
3. **Permissions → Repository permissions → Contents: Read and write** (שאר ההרשאות נשארות כמו שהן).
4. בחר תוקף (למשל שנה) ← **Generate**, והעתק את הטוקן.

### 3. הצפנת הטוקן
1. פתח `https://USER.github.io/ward-tv/setup.html`.
2. הדבק את הטוקן ובחר **קוד צוות** (לפחות 8 תווים).
3. הדף בודק שהטוקן עובד ומייצר ארבע שורות. ערוך את `config.js` ב-GitHub (אייקון העיפרון), החלף בהן את השורות `OWNER`, `REPO`, `BRANCH`, `TOKEN_ENC`, ולחץ **Commit**.

### 4. הטלוויזיה
- פתח בדפדפן של הטלוויזיה את `https://USER.github.io/ward-tv/` במסך מלא, וכבה מצב שינה.
- עדכונים מגיעים למסך תוך כדקה.
- אם האינטרנט נופל, מוצג המידע האחרון שנשמר.

### 5. הצוות
- שלחו לצוות את `https://USER.github.io/ward-tv/admin.html` ואת קוד הצוות.
- הצוות **לא צריך חשבון GitHub**, רק את הקוד.
- **נוכחות היום:** לוחצים "נמצא/ת" או "לא נמצא/ת". מי שיש לו ימים קבועים מופיע אוטומטית, וסימון ידני גובר על הקבוע.
- **סדר יום, הודעות, משפטים ותמונות:** בוחרים קבוע או זמני, וכל יום, ימים בשבוע או תאריך מסוים.
- **תמונות:** מעלים קובץ לתיקייה `images/` ב-repo וכותבים בדף `images/שם.jpg`.

## אבטחה ופרטיות – חשוב
- **אין להכניס שמות מטופלים או מידע רפואי.** ב-repo ציבורי, `data.json` גלוי לכל מי שמחפש אותו.
- הטוקן שמור מוצפן, ורק מי שיודע את קוד הצוות יכול לפענח אותו ולשמור שינויים. בחרו קוד ארוך (מילים ומספרים), כי קוד קצר אפשר לנחש.
- לטוקן יש הרשאה **רק** לקבצים של ה-repo הזה ולא לשום דבר אחר בחשבון.
- אם קוד הצוות דלף או מישהו עזב: מחקו את הטוקן ב-GitHub, צרו חדש, והריצו שוב את `setup.html` עם קוד חדש.
- כל שינוי נשמר ב-History של `data.json`, ואפשר לשחזר כל גרסה.
- מומלץ לבדוק מול מחלקת מערכות המידע של בית החולים לפני הפעלה.

## בדיקה בלי טוקן
כל עוד `TOKEN_ENC` ריק, דף הצוות שומר בדפדפן בלבד. אם פותחים את המסך ואת דף הצוות באותו מחשב, רואים במסך את מה שהוזן.
